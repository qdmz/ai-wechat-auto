# 语音使用说明（发给用户看的，照抄即可）

## 一、换成你自己的声音（克隆）
1. 用手机录音 App 录 10~16 秒，安静地方，像平时跟人说话那样自然说。可以念这段（把名字换成你自己的）：
   > 喂，你好，我是小王。上次说的那件事我已经办好了，你看什么时候方便，我们见面聊，或者我直接发给你也行。
2. 在微信「文件传输助手」里，把录音**当文件**发过去（mp3、m4a、wav 都行）。
3. 紧接着发一句命令，半分钟左右会收到一条试听语音：

| 想做什么 | 发这句 |
|---|---|
| 换成我自己的声音 | `克隆声音 本人` |
| 新加一个声音（如小美） | `克隆声音 小美` |
| 换掉已有的某个声音 | `克隆声音 小美`（写它的名字） |
| 用 Fish 网站上现成的音色 | `登记声音 小美 <32 位音色 id> 别名`（别名可写几个，空格隔开） |

不像就换一段更清楚的录音，再发一次同样的命令。

## 二、调声音效果（也在文件传输助手发，改完马上回一条试听）
| 想做什么 | 发这句 |
|---|---|
| 本人声音说快点 | `语速 1.3`（0.5~2，1=原速，默认 1.0） |
| 小美说慢点 | `语速 小美 1.0` |
| 小美更有感情 | `起伏 小美 0.9`（0.3~1，小=平稳，大=有感情，默认 0.7） |
| 听听某个声音念一句话 | `试听 小美 我下午三点到` |
| 看有哪些声音和参数 | `声音列表` |
| 忘了怎么用 | `语音帮助` 或 `声音帮助`（命令写错也会自动回用法） |

不写名字就是改本人的声音。

## 三、指定谁听什么声音（直接跟助理说）
- 「以后跟王总发语音用小美的声音」
- 「李四发语音也回文字」
- 「朋友和同学都用小美的声音」
- 「新加的小张声音，昵称叫小张，给同学用」（新声音要登记了才会用）
- 「现在有哪些声音？」
- 「小美说话再活泼一点」——改这个声音的说话风格
- 新加声音时，助理会问你这个人平时怎么说话，记成它的说话风格

## 四、规矩
- 助理没指定声音、或者指定错了，一律用本人的声音发，不会发不出去。
- 只有对方单聊发语音时才回语音，群里照常打字。
- 每个声音有自己的说话风格（你描述，助理记下），本人声音学你自己平时的说法。
- 用别人的声音，结尾一定会说「我是<你的称呼>私人助手<昵称>」，不会冒充本人。
